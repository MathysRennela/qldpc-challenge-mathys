[[55,33,6]] — GF(4) Hermitian quasi-twisted stabilizer code

Direction & hypothesis

Targeted high-rate general stabilizer codes (unrestricted / any weight) at moderate blocklengths ($55 \le n \le 77$) where Hermitian self-orthogonal multi-circulant and multi-eigenmode Vandermonde-bordered quasi-twisted codes over $\mathbb{F}_4$ achieve strictly higher minimum distance and logical rate than CSS constructions on the board. Strictly improves the online CodeTables.de minimum-distance lower bound for $[[55, 33]]_2$ from $5..8$ to $6..8$.

What was searched

Constructed exact Hermitian self-orthogonal $[55, 11]_4$ generator matrices in $\mathbb{F}_4[x]/(x^{11} - 1)$ (with $b_p = 0$ linearly independent norm-1 Vandermonde eigenmode border columns when $n \not\equiv 0 \pmod{11}$) via spectral Fourier / Meet-in-the-Middle norm matching and GPU minimum-weight screening, followed by $\mathbb{F}_2$ stabilizer basis reduction lowering maximum Pauli check weight from 38 to 28. Source archive: github.com/ramuza0113-sketch/qecc-codetables-2026 @ c6ec8ab, certificates/QECC_q2_n55_k33_d6.json (Zenodo DOI 10.5281/zenodo.24617669).

Evidence trail

  • Witness-backed upper bound in codes/55-33-6.json: d <= 6 (upper_bound), confirmed by cli/qldpc.py with 20,000 RIS trials plus 2,000,000 gf2_fast symplectic-doubling trials finding a minimum-weight Pauli logical witness of weight 6 and nothing lighter.
  • Independent 20-thread zero-symmetry clean-room Rust verification over $\mathbb{F}_4^{11}$ (github.com/ramuza0113-sketch/qecc-codetables-2026 @ c6ec8ab, verifiers/verify_hermitian_universal.rs) exhaustively proved zero nonzero codewords in $C^{\perp_H}$ of Hamming weight $\le 5$ ($d \ge 6$).
  • Verified locally with verify/qldpc_verify.py and verify/validate_candidate.py (passed: true).

Dead ends

  • Unbordered and single-column bordered ($b_p \in \{0, 1\}$) quasi-twisted searches missed residue classes $n = \ell m + b_p$ with $b_p \ge 2$, while naive repeated borders created weight-2 pure-border dual codewords; switching to distinct Vandermonde eigenmode border columns eliminated pure-border codewords up to weight $b_p$.
  • Raw Ashikhmin-Knill $\mathbb{F}_2$-symplectic expansion gave max check weight 38; Kruskal matroid greedy basis selection over low-weight stabilizer combinations reduced max check weight to 28 without altering the stabilizer group.

Tools

  • Harness: Google Antigravity. Author: @ramuza0113-sketch.
  • Repository tooling: cli/qldpc.py, verify/gf2_fast.cpp, verify/qldpc_verify.py, verify/check_codes_format.py, verify/check_prose.py, verify/check_submission_scope.py.
  • Compute: NVIDIA GeForce RTX 3090 GPU (< 0.2 GPU-hours per code).

Reproduction

5-block circulant Hermitian self-orthogonal [55, 11]_4 linear code [I_11 | M(a_1) | M(a_2) | M(a_3) | M(a_4)] over GF(4) = GF(2)[w]/(w^2+w+1) with first columns a_1 = (1+w, w, 1, 0, 1, 0, 1+w, w, 1+w, 1, 0), a_2 = (1, w, w, 0, 1+w, w, 1+w, 1, w, 1, 0), a_3 = (1, w, 1+w, w, 1, w, w, w, 1, 1, w), a_4 = (1, 0, 0, w, 1, 1+w, 1+w, 1, w, 1+w, w), basis-reduced over GF(2) from check weight 38 to max check weight 28. Full symplectic generator supports and Pauli logical witness are recorded directly in codes/55-33-6.json (also archived at github.com/ramuza0113-sketch/qecc-codetables-2026 @ c6ec8ab, certificates/QECC_q2_n55_k33_d6.json, Zenodo DOI 10.5281/zenodo.24617669).
