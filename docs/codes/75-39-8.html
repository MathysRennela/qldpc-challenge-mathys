[[75,39,8]] — GF(4) Hermitian quasi-twisted stabilizer code

Direction & hypothesis

Targeted high-rate general stabilizer codes (unrestricted / any weight) at moderate blocklengths ($55 \le n \le 77$) where Hermitian self-orthogonal multi-circulant and multi-eigenmode Vandermonde-bordered quasi-twisted codes over $\mathbb{F}_4$ achieve strictly higher minimum distance and logical rate than CSS constructions on the board. Strictly improves the online CodeTables.de minimum-distance lower bound for $[[75, 39]]_2$ from $7..12$ to $8..12$.

What was searched

Constructed exact Hermitian self-orthogonal $[75, 18]_4$ generator matrices in $\mathbb{F}_4[x]/(x^{18} - 1)$ (with $b_p = 3$ linearly independent norm-1 Vandermonde eigenmode border columns when $n \not\equiv 0 \pmod{18}$) via spectral Fourier / Meet-in-the-Middle norm matching and GPU minimum-weight screening, followed by $\mathbb{F}_2$ stabilizer basis reduction lowering maximum Pauli check weight from 48 to 32. Source archive: github.com/ramuza0113-sketch/qecc-codetables-2026 @ c6ec8ab, certificates/QECC_q2_n75_k39_d8.json (Zenodo DOI 10.5281/zenodo.24617669).

Evidence trail

  • Witness-backed upper bound in codes/75-39-8.json: d <= 8 (upper_bound), confirmed by cli/qldpc.py with 20,000 RIS trials plus 2,000,000 gf2_fast symplectic-doubling trials finding a minimum-weight Pauli logical witness of weight 8 and nothing lighter.
  • Independent 20-thread zero-symmetry clean-room Rust verification over $\mathbb{F}_4^{18}$ (github.com/ramuza0113-sketch/qecc-codetables-2026 @ c6ec8ab, verifiers/verify_hermitian_universal.rs) exhaustively proved zero nonzero codewords in $C^{\perp_H}$ of Hamming weight $\le 7$ ($d \ge 8$).
  • Verified locally with verify/qldpc_verify.py and verify/validate_candidate.py (passed: true).

Dead ends

  • Unbordered and single-column bordered ($b_p \in \{0, 1\}$) quasi-twisted searches missed residue classes $n = \ell m + b_p$ with $b_p \ge 2$, while naive repeated borders created weight-2 pure-border dual codewords; switching to distinct Vandermonde eigenmode border columns eliminated pure-border codewords up to weight $b_p$.
  • Raw Ashikhmin-Knill $\mathbb{F}_2$-symplectic expansion gave max check weight 48; Kruskal matroid greedy basis selection over low-weight stabilizer combinations reduced max check weight to 32 without altering the stabilizer group.

Tools

  • Harness: Google Antigravity. Author: @ramuza0113-sketch.
  • Repository tooling: cli/qldpc.py, verify/gf2_fast.cpp, verify/qldpc_verify.py, verify/check_codes_format.py, verify/check_prose.py, verify/check_submission_scope.py.
  • Compute: NVIDIA GeForce RTX 3090 GPU (< 0.2 GPU-hours per code).

Reproduction

4-block quasi-twisted Hermitian self-orthogonal [75, 18]_4 linear code over GF(4) = GF(2)[w]/(w^2+w+1) with 3 Vandermonde eigenmode border columns (eliminating pure-border comb codewords of weight <= 3), basis-reduced over GF(2) from check weight 48 to max check weight 32. Circulant block first columns: a_1 = (w, 1+w, w, 1, 1+w, w, 0, 0, 0, w, 1+w, 1+w, 1, 1+w, w, 1+w, 0, 1+w); a_2 = (0, 0, 1+w, 1+w, 0, 1+w, w, 1+w, 1+w, w, 1+w, w, w, 1+w, 1, 0, w, 1+w); a_3 = (0, 1, w, 1+w, 1, 1+w, 1, 1, 1, 1+w, 1+w, w, 1+w, 1+w, 1+w, 1, 0, 1). Eigenmode border columns: b_1 = (1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w); b_2 = (w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1); b_3 = (1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1, 1, w, 1). Full symplectic generator supports and Pauli logical witness are recorded directly in codes/75-39-8.json (also archived at github.com/ramuza0113-sketch/qecc-codetables-2026 @ c6ec8ab, certificates/QECC_q2_n75_k39_d8.json, Zenodo DOI 10.5281/zenodo.24617669).
